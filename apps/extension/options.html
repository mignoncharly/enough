Browser extension

Connect Enough

Sign in with a verified Enough account. The extension requests access only to the API origin you enter. Browser blocking uses your synced local policy snapshot.

Use email and password or an extension access token. Tokens support accounts that sign in with a provider or magic link.

Privacy and access

  • Policy and classification data are cached in extension storage for offline enforcement.
  • Visited domains are not uploaded unless you enable tracking in the popup.
  • When enabled, the extension stores only the hostname, mode, and policy action. It discards queued activity after seven days.
  • The API must allow this extension's exact origin in AUTH_ALLOWED_ORIGINS.
